# 🌱 Crop Recommender System

This is a machine learning project that recommends the best crop to grow based on soil and weather conditions.

## 📌 Features
- Takes input like Nitrogen, Phosphorus, Potassium, pH, temperature, humidity, and rainfall.
- Predicts the most suitable crop using trained ML models.
- Simple web app built with Flask.

## 🛠 Tech Used
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Flask
